# Studio Axion IA
Studio de fabrication de vidéos courtes assisté par IA (écriture de scripts, voix, montage, rendu), construit avec Next.js.
Les médias (vidéos, sons, photos) et les données de référence ont été retirés de cette version publique ; certains tests utilisent des médias synthétiques ou sont ignorés.
Il faut fournir ses propres clés et réglages : copier `deploiement/env.exemple` et renseigner vos valeurs.
