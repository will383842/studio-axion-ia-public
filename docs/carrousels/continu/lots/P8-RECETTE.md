# P8 — Recette (OPUS + le commanditaire) : après le déploiement par la session de déploiement (studio-rendu d'abord) sur « oui, déploie » écrit par le commanditaire
1. La session locale allume `carrousels-continus` (Réglages › Carrousels), puis crée par l'écran 3 carrousels continus :
   - un parcours PA ;
   - PB + 2 plaquettes ;
   - PC + 3 plaquettes en 3:4 ;
   - plus 1 par dépôt de session.
2. Tous les flux sont essayés dans un onglet NEUF : Valider, Refuser avec motif, Refaire, Corbeille et Restaurer, ZIP, générateur éteint, sujet contenant « Grenoble » (rouge).
3. Planche des 4 bandes ; notes /100 ; vérification à la loupe des coutures (JPEG) ; poids des fichiers.
4. Préparer, sans RIEN publier, les ZIP de l'essai réel. Le dépôt en BROUILLON sur Instagram et Facebook (rendu des coutures, recadrage, mosaïque Facebook) se fait SEULEMENT avec l'accord de le commanditaire. Recommandation : le commanditaire le fait lui-même dans l'appli, en 2 minutes ; sinon la session le fait sur son ordre écrit.
5. Demander à le commanditaire sa note de 1 à 5 par carrousel ; reporter ses retouches en lots P3x de suite.
6. Remettre l'interrupteur dans l'état que le commanditaire choisit (éteint par défaut).
