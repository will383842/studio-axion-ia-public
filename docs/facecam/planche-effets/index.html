Effets spéciaux — à la demande

Jamais posés tout seuls : seulement quand vous les demandez (« Monteur, … » au tournage, ou dans « Discuter avec mon monteur »). Chaque vidéo dure 5 s (1080 × 1920, 25 i/s).

Effets « main » (nouvelle version) : l'objet est posé sur la paume tournée vers le haut, main à plat devant soi, comme si on y posait un téléphone. Le plateau est un montage de deux vraies photos libres (une personne, une main paume vers le haut — photos de test publiées avec MediaPipe) : la main y bouge d'un bloc et ses doigts ne se replient pas, ce qui ne permet pas tout. L'essai final se fera sur une vraie prise de Will (main suivie par MediaPipe, lumière, reflets et grain mesurés sur la prise). Main retournée ou paume montrée de face : pas d'effet, « Effet non réussi — Réessayer » avec le conseil « montrez la paume ouverte vers le haut ».

Les quatre transitions restent sur le plateau dessiné (piste simulée).

  • Le visage n'est jamais caché ; un seul effet fort à la fois ; une transition dure de 0,6 à 1,5 s, calée sur le mot demandé.
  • Main pas trouvée assez longtemps : la vidéo sort sans l'effet, avec « Effet non réussi — Réessayer ».
  • Sur vos vraies prises, la main est suivie par MediaPipe (21 points : poignet, jointures, orientation de la paume) ; la lumière (direction, température), les reflets, le flou et le grain de l'objet sont mesurés sur la prise.
  • Option « ultra réaliste » (payante, coupée par défaut, seulement sur demande) : un passage de 3 à 5 s peut être retouché par IA (Higgsfield, Kling Omni Edit avec une image de référence de l'objet). Rien n'est envoyé tant que vous ne l'activez pas.
