# Vérification A3 — Complétude du format avocat (10/10/2026)

**Question unique : qu'est-ce qui MANQUE pour que le format avocat (script → double HeyGen → vidéo publiée) soit « parfait » selon Will ?**

- **Base :** master `fc894ae` (PR #22 incluse). Branche `verif/a3-completude-avocat`.
- **Sources :**
  - `docs/MOTEUR-AVOCAT-EXECUTION.md` (lots M0 à M4b, annexes) et `docs/BRANCHEMENTS-EXECUTION.md` ;
  - `docs/OUTILS-REELS-R0.md` à `R8.md`, `docs/controles/*` (dont `CORRECTEUR-REEL2.md`, 1re vraie vidéo du 04/10) ;
  - `docs/facecam/JOURNAL-F4.md` et `JOURNAL-H.md` (multicaméra et briques communes branchées sur l'avocat) ;
  - `docs/verification/V6-COMPLETUDE.md` (même méthode, pour le face caméra), `V4-ARGENT.md` et `V3-INTERFACE.md` ;
  - les exigences de Will rappelées dans la consigne de cette vérification ;
  - le code et les tests du dépôt.
- **Méthode :** lecture seule, en quatre audits parallèles (image et double HeyGen ; multicaméra, animations et bandeau ; chat, coût, langue et mention IA ; état réel des lots). Les constats les plus lourds ont été revérifiés à la main :
  - la multicaméra réservée aux prises filmées (`montage-avocat/index.ts:1045`, `estPrisesFilmees` l. 310) ;
  - le master intermédiaire 8 bits CRF 12 `ultrafast` (`studio-rendu/src/composition/image-ffmpeg.ts:362-364`) ;
  - `retoucheParPlan: false` (`montage-avocat/index.ts:1298`) ;
  - le fournisseur Claude qui recopie la simulation (`fournisseurs/claude/inscription.ts:68`) ;
  - `creerLook` gardé par un réglage, contrairement à son commentaire d'en-tête (`fournisseurs/heygen/visage.ts:20-22` contre `:176-178`).
- **Ce qui a été fait, et pas fait :** aucun code n'a été corrigé, rien n'a été fusionné ni déployé, aucun appel réel. Vitest n'a pas pu tourner dans ce conteneur (`node_modules` absent) : les statuts « testé » s'appuient sur les tests présents et les journaux.
- **Ce que veut dire « testé » :** un test existe et les journaux le disent vert. La mention précise « réel » (vrai FFmpeg, vrai appel HeyGen) ou « doubles » (simulation).

Légende des statuts :

- ✅ **fait et testé** ;
- 🟡 **fait, non testé** ;
- 🟠 **partiel** ;
- ❌ **absent** ;
- ⚠️ **trompeur** : le studio annonce la chose, mais elle n'a pas l'effet annoncé.

Effort estimé en jours de session cloud (j), tests compris.

## 0. En une phrase

La chaîne existe de bout en bout et **une vraie vidéo avocat a été fabriquée le 04/10** avec le vrai double de Will (`CORRECTEUR-REEL2.md:1`), mais :

- **l'image reste en 8 bits** avec une compression intermédiaire en plus ;
- **le double tourne en trois quarts, regard hors champ** (pas de face, regard objectif) ;
- **les 3 caméras ne marchent pas pour le double** (prises filmées seulement) ;
- **la modification par le chat après création est refusée en réel**, après avoir affiché un prix ;
- **aucune publication réelle n'est attestée**.
