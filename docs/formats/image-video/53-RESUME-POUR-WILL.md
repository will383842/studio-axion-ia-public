# Une image → une vidéo : le résumé

## Ce que vous aurez
Vous déposez une de vos infographies dans le studio. Il en sort une vidéo animée pour chaque réseau (TikTok, Instagram, Facebook, LinkedIn, YouTube Shorts), avec votre voix, dans le style de la v4, plus le texte à publier et l'endroit où poser le lien.

## Comment ça se passe pour vous
1. **Vous déposez l'image.**
2. **Le studio vous montre ce qu'il a compris** : chaque étape, chaque embranchement, chaque chiffre, à côté de votre image. Vous corrigez si besoin et vous validez. Obligatoire pour les 10 premières vidéos ; ensuite, seulement en cas de doute.
3. **Le studio écrit le script** dans votre ton : une accroche (deux au choix), le problème, l'explication complète étape par étape, la phrase-choc de votre image, puis une question liée à l'image pour faire commenter, et la fin habituelle de chaque réseau. Les phrases trop affirmatives (« zéro erreur ») sont surlignées avec une version plus prudente : vous choisissez. Vous voyez le prix, puis vous validez.
4. **La vidéo se fabrique** : votre voix, les éléments de l'image qui prennent vie, une vue d'ensemble du schéma quand il est grand, des bruitages, jamais de musique, des sous-titres que les boutons des applis ne cachent pas.
5. **Le studio vérifie avant de vous la donner** : il réécoute la voix, s'assure que la dernière phrase est dite en entier, que chaque chiffre est dit et montré, que rien n'est inventé, que tout est lisible. Une vidéo imparfaite est refusée, avec la raison en une phrase.

## Ce qui est déjà réglé (vous pouvez tout changer)
- **LinkedIn** : comme vous l'avez décidé le 12/10, rien n'est dit à la fin de la vidéo ; la question et le lien vont dans le texte du post.
- **Images très chargées** : une seule vidéo en 2 ou 3 parties. Si elle est trop longue pour un réseau, ce réseau reçoit une version plus courte, sans rien payer de plus.
- **Mot à commenter** : aucune vidéo ne promet d'envoyer quelque chose tant que le cadeau (votre image en grand + une page « comment ça marche ») n'existe pas.
- **Automatisations** : toujours présentées comme une « situation type », jamais comme un vrai client.
- **Photos de vraies personnes** : jamais reprises, on redessine.

## Ce que ça coûte
Environ **1 €** par image, toutes versions comprises (au plus 2,20 € ; jusqu'à 3 € pour une image très chargée). Rien n'est payé avant que vous ayez validé le script.
