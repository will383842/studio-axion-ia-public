# Modèle de script (exemple inventé)

Idée : ranger ses relances une fois pour toutes.

- Accroche : « Une relance oubliée coûte un client. »
- Douleur : « Vous y pensez le soir, jamais au bon moment. »
- Promesse : « Voyons ce qui change. »
- Ce qui change : « La relance part seule. Le client répond. Vous gardez le dernier mot. »
- Exemple : « Un artisan écrit son message une fois. Il part trois jours plus tard. »
- À retenir : « Écrivez une fois, laissez partir. »
