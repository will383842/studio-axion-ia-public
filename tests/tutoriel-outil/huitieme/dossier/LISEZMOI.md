# Espace démo · Atelier (8e tableau de bord, dossier volontairement partiel)

Maquette vivante d'un atelier de menuiserie. Toutes les données sont marquées « exemple ».

## Ce que contient le dossier
- `index.html` : trois écrans (commandes en cours, planning des machines, stocks de bois), chacun avec l'état « avant » (tableur en désordre) et l'état « maintenant ».
- `app.js` : `window.demoMaquette = { aller, reinitialiser }`.
- `demo-data.js` : les lignes d'exemple.
- `styles.css` : ivoire, noir, terracotta, police Manrope ; aucun script ni police externe.

## Ce qui manque exprès
- Aucun script de vidéo, aucun scénario de parcours : le maquettiste écrit le scénario, le scénariste écrit deux versions du script.
