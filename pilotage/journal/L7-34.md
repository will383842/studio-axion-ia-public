# L7-34 : pont infographie → Image→vidéo (journal)
fait : un clic sur une infographie DÉJÀ rendue crée la vidéo « Image → vidéo », sans nouveau rendu. `creerPontImageVideo` et `fichierImageVideo` (src/visuels/services/infographies.ts) : le fichier d'entrée est la clé du rendu (JPEG, dimensions du ratio), le dépôt est injecté, deux clics simultanés sur la même infographie et les mêmes réseaux partagent UN dépôt, un refus laisse le clic suivant possible. Action `creerVideoDepuisInfographieAction` (actions.ts) : interrupteur « infographies » vérifié en premier (éteint par défaut : GENERATEUR_ETEINT, aucun dépôt), puis le dépôt habituel `deposerImageVideo` avec le fichier de l'infographie ; le montant confirmé suit le chemin existant, rien n'est affiché ni décidé ici.
fichiers : src/visuels/services/infographies.ts, src/app/(studio)/image-video/actions.ts, src/formats/image-video/index.ts (une ligne : « à fournir » annonce l'infographie venue d'un clic), tests/visuels/pont-infographie-image-video.test.ts (nouveau).
choix : pas de nouvel interrupteur (interrupteur.ts hors liste) : le pont dépend de l'interrupteur « infographies » existant (éteint par défaut) ET du format « Image → vidéo », qui reste masqué (refus « pas raccordé » du dépôt). Taille du fichier mise à 0 (inconnue au pont) ; aucune écriture dans les services du dépôt d'image.
critères : un clic = un dépôt avec la clé de l'infographie, 0 soumission de rendu (tenu) ; deux clics simultanés = un seul dépôt (tenu).
tests : écrits rouges d'abord (fonctions absentes) ; fiche 8 passés, 0 échoué ; voisins (tests/image-video/interface et lot/depot-ecran) : 5 échecs, identiques sans ma branche (déjà là). tsc : 146 erreurs avant comme après (déjà là), aucune dans les fichiers touchés ; eslint sans erreur.
base : branche partie de usine/L6-02 (PR empilée).
reste : le bouton « Créer la vidéo » sur l'écran d'une infographie n'est pas posé (hors liste) ; l'enregistrement durable d'un « déjà fait » repose sur le contrôle « image déjà traitée » existant.
