# CAL-13b : brancher dans le calendrier les composants déjà livrés
- Fait (page.tsx, vue Semaine) : VueAgenda sur téléphone (860 px et moins) à la place de l'ancienne liste ; grille SemaineAvecApercu à partir de 861 px ; `criteres` (réseaux allumés) passés aux deux ; VueVide « semaine-passee » (semaine révolue vide) et « filtre-vide » (publications masquées par les filtres) ; BandeauAujourdhui (semaine en cours) ; AlerteProximite (sur les entrées gardées). Les données viennent toutes de la page.
- Retiré de page.tsx : l'ancienne liste mobile (LignePublication, EtatPublication) et ses imports, remplacés par l'Agenda. Le lien vers la vidéo est dans le tiroir (lienSource). Aucun bouton ni page supprimés.
- Fichiers : src/app/(studio)/calendrier/page.tsx, tests/calendrier/cal-13b-branchement.test.tsx (nouveau), tests/rc-36-apercu.test.tsx et tests/final-b-mobile.test.ts (ils lisaient l'ancienne liste mobile), ce journal.
- Reste : Filtres (second bouton « Filtrer », plus de 6 commandes, et état client sans adresse : il faut un filtre dans l'adresse) ; VueVide « vide » (calendrier entièrement vide : exige une donnée « aucun contenu planifié » que la page n'a pas) ; PretAPartir, DecalerEntree, ApercuMedia, AjouterEntreeProposant (données ou actions serveur nouvelles). Le `criteres` ne porte que les réseaux : types, états et mot cherché attendent Filtres.
- Rendu non vérifié dans un navigateur.

## Corrections après relecture (CAL-13b-corr)
- Fait : (1) sans `?reseaux=`, les quatre réseaux allumés = aucun filtre, donc YouTube et YouTube Shorts restent visibles (grille et Agenda), sans « filtre-vide » à tort ; (2) sur téléphone, l'état redit l'ancienne ligne : envoi refusé, absent ou échec = « À corriger », « À vérifier », « Envoi en cours », « Brouillon dans Buffer » (calculé dans page.tsx, mots dans VueAgenda) ; (3) le titre de chaque jour de l'Agenda est de nouveau un lien vers la vue Jour (prop `lienJour`, « Ouvrir la journée du … », filtres gardés) ; (4) le nom du compte visé (`canalNom`) porte jusqu'à l'Agenda : une ligne « · nom » sous la carte (fichier en plus : `apercu-reseau.ts`, qui porte `canalNom`).
- Mineurs faits : bandeau d'aujourd'hui et alerte de proximité ne reçoivent plus les essais ; le compteur « N publications » suit le filtre des réseaux (les essais comptés à part) ; « Semaine libre » et « semaine passée » ne sont montrés que sur ordinateur (l'Agenda dit déjà chaque jour vide) ; commentaire périmé corrigé.
- Note : la bascule passe de 1024 px (`lg`) à 861 px : la grille 7 colonnes apparaît donc entre 861 et 1023 px.
- Tests : `cal-13b-branchement` (rendu de la page : YouTube visible, pas de filtre-vide, statuts Buffer, lien du jour, compte visé, compteur), `final-b-mobile` (contrôle réel du compte visé), `rc-36` (la carte de l'Agenda ouvre le tiroir, lien `/videos/…` présent).
- Reste : inchangé (Filtres, VueVide « vide », PretAPartir, DecalerEntree, ApercuMedia, AjouterEntreeProposant). Rendu non vérifié dans un navigateur.
